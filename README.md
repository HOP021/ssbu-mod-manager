# スマブラSP MODマネージャー byほっぷ

スマブラSP（Switch）の MOD を、**Android だけ**で「探す → 変換する → SDカードに入れる」ためのアプリです。パソコンは要りません。

> 非公式のファンメイドツールです。任天堂、GameBanana とは関係ありません。キャラの画像などの権利は、各権利者にあります。

## ダウンロード

[**Releases**](../../releases) から、いちばん新しい版の APK をダウンロードして、インストールしてください。上書きでアップデートできます。
（「提供元不明のアプリ」を許可する必要があります。）

## できること

### 🔍 探す
- GameBanana の MOD を、アプリの中で検索してダウンロード
- キャラを選ぶと、そのキャラのスキンだけを検索（別キャラの MOD が混ざりにくい絞り込み）
- カテゴリー（スキン・ステージ・音楽・UI・エフェクトなど）で絞り込み
- 「📄 詳細」で MOD の説明を日本語に自動翻訳して表示
- 画像をタップすると、プレビュー画像を全部表示
- 複数の同時ダウンロード、ダウンロード履歴、お気に入り、更新チェック

### 🔧 作る（変換）
- zip / rar / 7z や、解凍済みのフォルダを読み込んで変換
- スロットの入れ替え・追加、複数のスキンを1つにまとめる
- ステージ MOD、ムーブセットなどの共通ファイルも、スキンと一緒にまとめて出力
- 追加スロット（c08〜c15）に対応（必要なときだけボタンで表示）
- キャラ名・サブタイトルの編集。メモ欄が空なら、元の MOD 名を自動で入力
- まとめた MOD を開き直しても、メモとスロットごとのプレビュー画像が残る
- `config.json` の引き継ぎ、テクスチャの自動登録、勝利BGMの引き継ぎ
- 書き出し前に、追加・変更されるファイルを確認（変更差分表示）
- 書き出す MOD の名前は、キャラの番号つきで自動で付く

### 🛡 安全のしくみ
- **c00 保護モード**: 通常スキンを上書きしないようにロック
- **上書き確認**: 同じキャラ・同じスロットの導入済み MOD があると警告
- **導入前バックアップ**: 重なる導入済み MOD を自動で退避（無効化）
- **ロールバック**: 直前の操作を取り消し
- **互換性チェック**: 対応バージョンや、必要なプラグインを表示
- **必要なプラグインの導入**: ARCropolis などを、アプリから導入（またはその配布ページを開く）

### 📁 管理
- 導入済み MOD の一覧、有効／無効の切り替え、削除
- キャラごとのスロット配置の一覧（どのスロットが空いているかが分かる）
- 同じファイルを持つ MOD の衝突の検出
- 並び方の切り替え（リスト／タイル）、ライト／ダークのテーマ

### ⚙ その他
- 変換中や書き出し中にアプリが閉じにくくなる常駐のしくみ（終了は手動）
- sdmc フォルダの選択、プラグイン（Skyline・ARCropolis）の状態確認と導入

## 使い方

1. 「その他」タブで、SDカードの `mods` フォルダを選びます（最初の1回だけ）。
2. 「探す」タブで MOD をダウンロードします。持っているファイルを使うときは、「変換」タブで読み込みます。
3. スロットや名前を設定して、書き出します。
4. Switch の SD カードに入れて、ゲームを起動します。

## 注意

- 個人で使う前提のツールです。MOD の再配布には使わないでください。
- 元の MOD の作りによっては、モデルが黒く（白く）なる、ロード画面で止まる、エラーで止まることがあります。
  - 例: スロット専用エフェクトを含む MOD で「Error Code: 2--0069 … is unloaded」と出るとき → 変換タブの「エフェクトを含めない」をオンにして書き出し直してください。
- 取りこぼし防止のため、変換でファイルが外れたときは理由を表示します。
- 実機で確認が取れているのは基本機能です。新しめの機能は、状況によって期待どおりに動かないことがあります。不具合があれば、Issues で教えてください。

## 動作環境

- Android 端末（SDカードの `ultimate/mods` を選べること）
- Switch 側は、Skyline と ARCropolis が入っていること（アプリから導入もできます）
